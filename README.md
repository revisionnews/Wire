# Revision Wire

The Revision News office board of San Antonio and Bexar County news.

- `index.html` is the TV page (16:9, scrolling).
- `m/index.html` is the phone page each QR code opens.
- `data.json` holds the stories. It is the only file the refresh robot changes.

The design is locked; see the Revision News project doc `dispatch-design-lock.md`.
